    Image generation

OpenAI Images, OpenRouter Image API, and a signed-in Codex ChatGPT plan are supported.     Video generation
    
              
    Pick the model used by the generate_video tool. This is separate from the chat model and the video fallback — any chat model can orchestrate, and the video backend is resolved here. OpenRouter's async /videos API is supported. Leave disabled until you want the agent to be able to generate videos.
    
              
            
    
            
    
              
    Speech generation
    
              
    Speech generation
    
              
    Pick the model used by the generate_speech tool (text-to-speech). Online models use an OpenAI-compatible /audio/speech endpoint; the offline piper engine works without any API key when installed. If the online model fails, NusaShell automatically falls back to offline.
