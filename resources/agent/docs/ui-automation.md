# Automation

Manage durable once/every/when automations, inspect DAG runs, and see waiting or blocked states without occupying a runner.

**How to open:** Click the Automation item in the left sidebar.

## Header stats

Counts of runnable, blocked, and waiting automations so provider outages are visible without opening a run. On small screens the stats wrap below the header copy.

- **`#auto-stat-runnable`** (missing map entry)

- **`#auto-stat-blocked`** (missing map entry)

- **`#auto-stat-waiting`** (missing map entry)

## Toolbar

Tabs switch between Workflows, Runs, Schedules, and Events. New automation opens a once/every/when/manual wizard. Pipeline files from the data directory appear alongside saved automations in the Workflows tab. On phones the tabs can scroll horizontally without widening the page.

- **`#auto-tabs`** (missing map entry)

- **`#auto-tab-workflows`** (missing map entry)

- **`#auto-tab-runs`** (missing map entry)

- **`#auto-tab-schedules`** (missing map entry)

- **`#auto-tab-events`** (missing map entry)

- **`#auto-new-btn`** (missing map entry)

## Blocked provider

When a saved automation depends on a disabled MCP provider it stays BLOCKED rather than FAILED. Enable provider restores the binding without rewriting the workflow.

- **`#auto-blocked-banner`** (missing map entry)

- **`#auto-blocked-text`** (missing map entry)

- **`#auto-enable-provider-btn`** (missing map entry)

## List and detail

The list shows the active tab. The detail pane renders job needs as a DAG, waiting wake times, and run/enable/disable/cancel actions.

- **`#auto-list`** (missing map entry)

- **`#auto-list-title`** (missing map entry)

- **`#auto-list-count`** (missing map entry)

- **`#auto-detail`** (missing map entry)

- **`#auto-detail-title`** (missing map entry)

- **`#auto-detail-actions`** (missing map entry)
