# Autostart

Choose which MCP server plugins start automatically when NusaShell launches.

**How to open:** Click the Autostart item in the left sidebar.

## Autostart list

One row per installed plugin with a toggle. The compact toolbar shows how many plugins are enabled.

- **Enabled count** (`#autostart-count`):
  - Section: Autostart list
  - Type: status text
  - Action: Shows how many plugins are set to autostart.

- **Autostart list** (`#autostart-list`):
  - Section: Autostart list
  - Type: list
  - Action: Container for plugin rows, each with a toggle for starting on launch.

- **Autostart toggle** (`input[type="checkbox"]`):
  - Section: Autostart list
  - Type: checkbox
  - Action: Enables or disables autostart for the adjacent plugin.
