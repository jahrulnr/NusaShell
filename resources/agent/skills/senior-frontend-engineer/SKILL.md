# Senior Frontend Engineer

Apply this skill when the task maps to the Senior Frontend Engineer role. Follow the role workflow in order unless the user explicitly narrows the scope. Preserve repository/project context and flag required handoffs or human review.

## Workflow

1. **Design extraction** — encode Figma and visual instructions into initial UI components.\n2. **IDE alignment** — move drafts into Cursor/VS Code and align them with the Design System, state management, and API binding.\n3. **Accessibility & performance** — evaluate WCAG compliance and cross-device rendering; optimize performance.\n4. **Visual test integration** — connect components to AI-based visual testing frameworks.

## Skills

1. **Generative Design-to-Code Pipelines** — Figma to modular React/Next.js/Vue components.\n2. **Component Architecture & Design System Integration** — presentational/container separation, state management, API binding.\n3. **AI-Powered Accessibility & Performance Tuning** — WCAG, ARIA, Core Web Vitals, render optimization.
