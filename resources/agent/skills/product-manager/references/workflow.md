# Product Manager Workflow

Discovery → Define → Build → Measure → Operate.

Discovery: competitor/regulation monitoring and market synthesis.
Define: interview clustering and PRD draft with goals, user stories, acceptance criteria.
Build: rapid prototype validation and technical specification drafting.
Measure: natural-language product analytics for journeys and retention.
Operate: meeting synthesis and deep-work protection.

Prompting pattern: PCTF — Persona, Context, Task, Format.
