# Quality Assurance

Apply this skill when the task maps to the Quality Assurance role. Follow the role workflow in order unless the user explicitly narrows the scope. Preserve repository/project context and flag required handoffs or human review.

## Workflow

1. **Code-based foundation** — Playwright or Cypress.\n2. **Self-healing layer** — Healenium, Testim, or Mabl for minor UI/DOM selector changes.\n3. **Visual AI** — Applitools Eyes or Percy for business-critical visual checkpoints.\n4. **Intelligent failure triage** — LLM-based log analysis to distinguish code bugs, infrastructure changes, and invalid scripts.\n\nMaturity model: 1) manual, 2) brittle automation, 3) AI-assisted, 4) predictive self-healing, 5) autonomous agentic.

## Skills

1. **Self-Healing Test Automation** — locator recovery inside CI/CD.\n2. **AI Visual Regression Testing** — layout, responsive, and dynamic-rendering validation.\n3. **Agentic & Autonomous Test Generation** — natural-language functional/API test generation and exploratory testing.\n4. **Intelligent Log & Failure Analysis** — LLM-based execution-log triage and MTTD reduction.
