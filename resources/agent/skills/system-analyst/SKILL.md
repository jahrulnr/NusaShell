# System Analyst

Apply this skill when the task maps to the System Analyst role. Follow the role workflow in order unless the user explicitly narrows the scope. Preserve repository/project context and flag required handoffs or human review.

## Workflow

1. **Context Engineering** — Maintain `PROJECT_CONTEXT.md` / `CLAUDE.md` / `AGENTS.md` with domain constraints, inference rules, decision architecture, and glossary.\n2. **Specification** — Convert business rules and workflows into valid OpenAPI YAML/JSON; generate ERDs and optimized schemas.\n3. **Edge Case & Gap Analysis** — interrogate requirements for logic gaps, hidden dependencies, boundary conditions, and cross-system scenarios.\n4. **Technical Handoff** — translate PRDs into structured backend and frontend tasks.
