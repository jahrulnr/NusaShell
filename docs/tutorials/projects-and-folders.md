# Organize work with projects

A project groups related conversations and the folders they should work in. Use one for a codebase, a research area, or another task that needs the same context across conversations.

## Create a project

1. Select **+** beside **Projects** in the sidebar.
2. Give the project a name.
3. Add one or more existing folders. The first folder is the project's primary working folder.
4. Save the project.

Create a conversation from the project in the sidebar, or move an existing conversation into it from that conversation's menu.

## Work across folders

The project folders become the workspace for conversations in that project. The primary folder is the working directory; additional folders provide more context to the agent and its file tools.

You can also choose a project or working directory when starting a conversation. A conversation outside a project can still use its own working directory.

## Keep the sidebar useful

Pin important projects or conversations, collapse project groups you are not using, and search for a conversation from the sidebar. These changes organize the conversation list without changing the underlying files.
